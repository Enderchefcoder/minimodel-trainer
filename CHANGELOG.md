# Changelog

All notable changes to this project are documented here. The format follows

## [0.1.0] - 2026-08-02

The initial complete toolkit.

### Language models
- Four architectures behind one interface: dense (RMSNorm/RoPE/SwiGLU/GQA/
  QK-norm/window patterns), looped (the supra2 recurrent-depth design with
  per-iteration LoRA/gain conditioning and inference-time depth control),
  sparse MoE (shared expert, aux-loss-free balancing), hybrid RG-LRU/attention
  (Griffin-style) — all with exact-equivalence incremental KV caching.
- 13 verified size templates, 1.4M → 343M params, generated by
  `scripts/generate_templates.py`; `supra2_1406240.yaml` doubles as the
  annotated architecture specification.

### Data & tokenization
- Self-contained byte-level BPE (total split pattern, HF interop, optional
  Rust-backed training) + chat template with baked-in loss masking and
  reasoning spans.
- Declarative registry: 48 text datasets + 10 mixtures across pretrain/
  synthetic/SFT/CoT/preference/RLVR/eval; memmapped token shards with
  optional label arrays; deterministic packed/supervised/mixture loaders;
  bundled offline corpus.

### Training
- Step-driven `Trainer` (AMP, accumulation, clipping, cosine/WSD/linear/
  constant/inverse-sqrt schedules, AdamW/Muon/Lion/SGD, bit-exact resume,
  retention, ETA, divergence guard, callbacks) and subclasses: SFT (replay,
  masking, accuracy), CoT (reasoning-span weighting, think-close term), DPO
  (sigmoid/IPO/hinge/CPO), RLVR (GRPO + pluggable verifiers), SPIN
  (regenerating self-play). YAML recipes with `extends:` under `configs/`.

### Vision
- DiT (rectified flow, class/text conditioning, batched CFG), UNet, PixelGPT
  (24×24 palette pixel art, ~10M params, row/col embeddings), instruction
  edit model (dual guidance), f8 VAE; palette tooling, uint8 image shards,
  synthetic-sprite generator; flow/DDPM trainers with EMA; Euler/Heun/DDIM/
  DDPM samplers; 10 verified templates.

### Tooling
- `minimodel`/`mmt` CLI covering the whole lifecycle incl. `quickstart` and
  `vision quickstart` (offline, ~1 min each); evaluation harness
  (likelihood-scored MC/minimal-pairs, verifier generation, perplexity,
  prefill/decode throughput); comparison tables and charts with ASCII
  fallbacks; five merge methods; model cards generated from run artifacts.
- 455 offline tests (~90% line coverage), `scripts/smoke_e2e.py`, ruff
  config, CI workflow, docs (17 pages), research notes, AGENTS.md.
