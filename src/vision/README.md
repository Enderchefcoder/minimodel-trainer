# vision/

The image-model pipeline, mirroring the text one.

- `architectures/` — `dit.py` (rectified-flow diffusion transformer,
  class/text conditioning, batched CFG), `unet.py` (conv diffusion for small
  data), `pixelgpt.py` (autoregressive palette pixel art; the 24×24 config is
  ~10M params), `edit.py` (InstructPix2Pix-style editing with dual guidance),
  `vae.py` (latents for >64px), shared `layers.py` (AdaLN-Zero, patching,
  timestep/label/text conditioning), `registry.py`.
- `data/` — palette extraction/quantization (exact/median-cut/k-means),
  memmapped uint8 image shards, datasets (RGB, palette sequences, edit
  pairs), `synthetic_sprites` for offline work.
- `training/` — `diffusion.py` (flow matching + DDPM, logit-normal timesteps,
  EMA), `pixel_trainer.py` (AR pixels + the VAE trainer).
- `sampling/` — Euler/Heun/DDIM/DDPM samplers, grids, PNG/palette output.
- `templates/` — 10 sizes, generated by `scripts/generate_vision_templates.py`.
- `recipe.py` / `cli.py` — `minimodel vision …`.
